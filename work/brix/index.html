A portfolio you can ask questions.

Brix is this site: a chat whose answer engine runs in your browser, with no backend and no API key. I designed it, wrote the engine, and tested it like a product.

01 · The engine

Ask if it's a real AI and it shows you its code

It matches your question against a knowledge base I wrote about my work, and it says so when it doesn't know.

02 · The audit

I tested it like a real product

I ran real screening questions through the engine. The first pass sent "show me her strongest case study" to my college degree, so I fixed how it weighs words and kept that question in the test set.

This site is a working sample of how I build: frame the product, design it, write the code, then test it like someone else's. The same loop I'd bring to your team.
