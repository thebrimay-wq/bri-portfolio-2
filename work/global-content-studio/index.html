01 · At a glance

I saw the gap, built v1 alone, and rebuilt it twice with engineers

Nobody asked for this. I named the risk, built the first version myself, and carried it through two rebuilds as the company made it part of its platform.

The problem

Writers drafted on personal AI tools. Drafts drifted off-voice, and nobody recorded which claims had been checked. Then the company set its sights on new markets.

The bet

A studio that already knows our voice, our compliance rules, and each market's facts, with a person signing off on everything.

My role

v1 designed and coded solo. In v2 and v3 I specced and built the review experience while engineers rebuilt the pipeline.

Team

v1 solo · v2 and v3 with two engineers · localizers reviewing the output

Built with

TypeScript · Lit · React · Python · a Cloudflare Worker · Azure · Anthropic and Gemini APIs · built with Claude Code

Status

In production · 8,118 localized variants across 28 locales, Sep 8, 2026

04 · Decisions

Four calls I'd make again

A per-locale wiki, not open-web search

Financial facts have to be ours. Web search feeds the wiki; it never bypasses it.

Five model calls per article, not one

One-pass drafts kept US framing that no check could see. Five passes cost more and caught it.

The score routes; it doesn't gate

The model grading itself decides what a reviewer sees first. There is no publish threshold in the code, on purpose.

Approved is a state automation can't cross

Runs skip approved work. Re-localizing it takes a named, explicit request.

05 · What broke

It worked. Then it hit the limits of a tool one person built.

I wrote down four failures. They open the spec for the next version.

01Lost edits

A re-run replaced work a localizer had corrected. On three reviewed articles, none of the reviewed sentences survived.

02Flags hard to act on

One Bulgarian run raised 630 flags on 445 articles, 78% of them "check this number", in a separate tab with no action.

03No audit trail

A name prompt in the browser stood in for sign-in. Nobody could say who approved what.

04Slow at scale

Every request parsed a 3.5 MB index, and the Worker hit its CPU limit.

06 · v2 and v3, with engineering

Engineers rebuilt the pipeline. I built what people touch.

v2 moved localization to Python on Azure, and I built the review console and its API. v3 put the same review inside the company's admin platform, with an editor for people who don't write markup.

07 · Designing the AI

A person always outranks the model

Nothing is trained. Everything is prompted, grounded in a per-locale wiki, checked by a separate pass, and approved by a person.

A skeptical second read

A verify pass reads each draft as a native reader would, with typed failures and a redo loop. I wrote it with Claude Code. A plain check then strips US links and terms.

Pictures get the same care

The header image gets a cultural read, a brief, a check, and a person. A localizer's "Flag for redo" beats any score.

Checked, not assumed

221 tests cover the gate, the policy, the rewrite, and the index. Of 75 UK articles the fit check dropped, 62 couldn't honestly exist there.
